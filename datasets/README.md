# Bundled Iris data

`iris.csv` is the `iris.data` file from the [UCI Machine Learning Repository's Iris dataset](https://archive.ics.uci.edu/dataset/53/iris), downloaded from [UCI's distribution archive](https://archive.ics.uci.edu/static/public/53/iris.zip) on 2026-10-03. A header was added and blank lines removed; numeric values, labels, and row order are unchanged. The 150 rows contain sepal length, sepal width, petal length, and petal width (all centimeters), followed by species. Each species has 50 observations.

Dataset citation: Fisher, R. (1936). *Iris* [Dataset]. UCI Machine Learning Repository. [DOI:10.24432/C56C76](https://doi.org/10.24432/C56C76).

UCI distributes this dataset under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). This bundled adaptation retains attribution to Fisher and UCI.

This is UCI's `iris.data` version, not `bezdekIris.data`. UCI documents discrepancies between this version and the historical dataset in records 35 and 38. We preserve the distributed values and do not silently correct them. The chapter is an exploration of the supplied UCI observations, not an exact reproduction of Fisher's historical analysis.
